## Brand & Style

This design system translates the visual identity of the brand into a refined, high-end dark mode luxury fintech experience. The personality balances institutional heritage and sovereign stability with modern digital dynamism, creating an aura of prestige, liquidity, and security.

Targeted at discerning wealth management clients, institutional investors, and modern financial operators, the interface evokes quiet confidence, calm precision, and energetic prosperity. The visual aesthetic fuses dark mode luxury minimalism with subtle luminous glassmorphic tiers. Deep midnight indigo and obsidian violet foundations prevent eye strain and establish depth, while vibrant sunset amber accents guide attention effortlessly to actionable metrics, key state transitions, and primary conversions without visual friction.

## Colors

The color palette captures the regal warmth of the brand assets, calibrated specifically for an ultra-deep dark environment:

- **Primary (`#F57224`)**: Vibrant sunset orange serves as the active pulse of the system—reserved for primary calls to action, high-priority status indicators, focused controls, and radiant micro-accents.
- **Secondary (`#241468`)**: Deep royal indigo forms structural framing, interactive resting surfaces, and base canvas gradations.
- **Tertiary (`#FF914D`)**: Radiant amber-peach used for subtle glow halos, chart metrics, accent badges, and complementary gradient stops.
- **Neutral Canvas (`#0D081E`)**: A deep, pitch-night violet black that replaces pure harsh `#000000`, anchoring the interface with optical richness.
- **Surface Tiers**:
  - `surface-base`: `#0D081E` (canvas backdrop)
  - `surface-raised`: `#160E2E` (navigation headers, sidebars)
  - `surface-overlay`: `#1F153F` (standard interactive cards, modal surfaces)
  - `surface-elevated`: `#2E1E5C` (hover states, segmented tabs, active sheets)
- **Text & On-Color Tokens**:
  - `text-primary`: `#FFF5EB` (warm-white pearl, ensuring clear contrast against dark violet)
  - `text-secondary`: `#B8AFD0` (subdued muted lavender)
  - `text-tertiary`: `#7D7299` (de-emphasized meta information)
- **Luminous Gradients**:
  - Hero card gradient: `linear-gradient(135deg, rgba(36, 20, 104, 0.9) 0%, rgba(46, 26, 125, 0.7) 45%, rgba(245, 114, 36, 0.22) 100%)`
  - Accent stroke gradient: `linear-gradient(135deg, rgba(255, 107, 0, 0.5) 0%, rgba(36, 20, 104, 0.1) 100%)`

## Typography

The typographic hierarchy harmonizes elegance, readability, and financial clarity:

- **Headlines (`Plus Jakarta Sans`)**: Modern, geometric, yet possessing organic curves that echo the brand's friendly heritage while remaining commanding and authoritative.
- **Body (`Manrope`)**: High legibility, neutral balance, and open letterforms that render crisp financial data, disclosures, and dense transactional records.
- **Labels & Data Metrics (`Space Grotesk`)**: Technical, structured, and legible at small sizes, ensuring tabular balance for currency figures, portfolio percentages, timestamps, and ticker badges.

### Responsive Scaling Rules
Headlines step down dynamically on mobile devices (e.g., `display` reduces from `3.5rem` to `2.25rem`, `headline-lg` steps down to `headline-lg-mobile` at `1.75rem`). Body text scales strictly preserve vertical rhythm and baseline grid alignment across viewport sizes.

## Layout & Spacing

A disciplined 12-column fluid grid system governs the desktop layout, transitioning to an 8-column layout on tablets, and a 4-column layout on mobile viewports.

### Grid & Breakpoints
- **Desktop (≥ 1200px)**: 12 columns, `gutter: 1.5rem`, max outer canvas container of `1440px` centered with `margin: 3rem`.
- **Tablet (768px – 1199px)**: 8 columns, `gutter: 1.25rem`, outer section margin `2rem`.
- **Mobile (< 768px)**: 4 columns, `gutter-mobile: 1rem`, canvas margins `margin-mobile: 1.25rem`.

### Density & Rhythms
A strict 4px/8px modular spacing system maintains spatial cadence across all card groupings, financial summaries, and form layouts. Vertical separation between thematic card sections leverages `space-xl` (40px), while inner card padding utilizes `space-lg` (24px) on desktop and `space-md` (16px) on mobile for optimal information density without crowding.

## Elevation & Depth

Visual hierarchy uses a layered combination of tonal layering, soft ambient glows, and illuminated perimeter highlights:

1. **Base Layer (Level 0)**: Background `#0D081E` provides the deepest foundation.
2. **Plates & Ambient Containers (Level 1)**: Solid tonal containers `#160E2E` with a hairline ghost border (`1px solid rgba(255, 245, 235, 0.06)`).
3. **Glassmorphic Financial Cards (Level 2)**: Translucent indigo backdrops (`rgba(31, 21, 63, 0.72)`) with a `backdrop-filter: blur(16px)` and dual-tone linear edge stroke (`border: 1px solid rgba(245, 114, 36, 0.25)` top-left transitioning to `rgba(36, 20, 104, 0.4)` bottom-right).
4. **Active & Floating Overlays (Level 3)**: Modals, tooltips, and action dropdowns utilize deep ambient shadows:
   - Box shadow: `0 12px 36px -8px rgba(0, 0, 0, 0.6), 0 0 24px 0 rgba(245, 114, 36, 0.12)`.
5. **Sunset Halo Effect**: Key balance cards and premium tier elements project a diffused outer aura (`box-shadow: 0 0 40px -10px rgba(245, 114, 36, 0.2)`), imparting liquid warmth without causing visual clutter.

## Shapes

The design system adopts a rounded shape language (`roundedness: 2`), reflecting the smooth, continuous contours of the brand emblem:

- **Base Radius (`0.5rem` / 8px)**: Used for input fields, list items, small interactive chips, and badge components.
- **Large Radius (`1rem` / 16px)**: Used for content modules, financial instrument cards, table enclosures, and modal containers.
- **Extra-Large Radius (`1.5rem` / 24px)**: Dedicated to feature hero banners, premium vault containers, and bottom sheets on mobile.
- **Pill Form factor (`9999px`)**: Specifically reserved for interactive trigger buttons, status indicators, and segment filter tags.

## Components

### Buttons
- **Primary**: Pill-shaped button featuring a vibrant sunset gradient fill (`linear-gradient(135deg, #FF6B00 0%, #F57224 100%)`), text in `#FFF5EB`, medium label styling, with a hover illumination (`box-shadow: 0 4px 18px rgba(245, 114, 36, 0.35)`).
- **Secondary / Ghost**: Deep royal indigo container (`rgba(36, 20, 104, 0.45)`) bordered with `1px solid rgba(255, 245, 235, 0.15)`, text in `#FFF5EB`. Hover state elevates the border to `rgba(245, 114, 36, 0.5)` with an inner soft amber wash.

### Cards & Wealth Tiles
- Structured using Level 2 glassmorphism (`rgba(31, 21, 63, 0.72)` background, `backdrop-filter: blur(16px)`).
- Card corners are `1rem` (16px) with an asymmetrical inner border gradient highlighting top and left edges.
- Premium balance and investment cards incorporate a subtle radial sunset ember glow anchored in the upper-right corner.

### Input Fields
- Dark enclosed surfaces (`#160E2E`) with a smooth 8px border radius.
- Resting border: `1px solid rgba(184, 175, 208, 0.2)`.
- Focused state: Border transitions to `#F57224` accompanied by an ambient focus ring (`box-shadow: 0 0 0 3px rgba(245, 114, 36, 0.2)`). Text remains crisp in `#FFF5EB` with placeholder in `#7D7299`.

### Chips & Filter Tags
- Pill-shaped with compact padding (`0.25rem 0.75rem`).
- Resting: Transparent surface with `1px solid rgba(184, 175, 208, 0.15)` and `#B8AFD0` text.
- Active: Amber-infused royal violet (`background: rgba(245, 114, 36, 0.15); border-color: #F57224; color: #FFF5EB`).

### Checkboxes & Radio Controls
- Base form in 8px radius for checkboxes, circular for radios.
- Unchecked: Outlined in `rgba(184, 175, 208, 0.3)`.
- Checked: Solid `#F57224` fill featuring a warm `#FFF5EB` check icon or dot, with an orange micro-glow on focus.

### Financial Lists & Transaction Rows
- Framed in clean horizontal tiers separated by hairline dividers (`rgba(255, 245, 235, 0.05)`).
- Hover effect produces a subtle royal violet highlight (`#1F153F`) across the full row with smooth transitions.
